SLT3 — Effective exponents and temperature

Singular learning theory day, Iliad Intensive 2026

To run the code, open slt3_temperature.ipynb in Jupyter (CPU only; needs numpy and matplotlib). Every code cell's output is shown on this page; exercise solutions are folded under Solution.

The learning coefficient \lambda is defined by an n\to\infty limit, and an arbitrarily small change to the loss can change it. This notebook asks what is actually measurable at finite n. It defines an effective exponent \lambda_{\rm eff}(n), shows how it crosses over between two values of \lambda, and then builds the estimator people use: a posterior at an inverse temperature \beta<1, sampled with SGLD.

Keystone readings. Lau et al. for the estimator; Furman’s notebook for a runnable route to it.

3.1 The pathology

Question. \lambda is the exponent of a t\to0 limit. How stable is it, and what does a finite sample see instead?

Notation. K(w)=L(w)-L(w_0) is the population loss measured from its minimum, \varphi the prior, \bar Z_n=\int\varphi\,e^{-nK}dw and \bar F_n=-\log\bar Z_n. The learning coefficient \lambda and its multiplicity m are defined by the prior volume of a sublevel set, V(t)=\int_{K<t}\varphi\sim c\,t^{\lambda}(-\log t)^{m-1} as t\to0, and then \bar F_n=\lambda\log n-(m-1)\log\log n+O(1) (NB2 §1).

You’re measuring model complexity wrong, Jesse Hoogland and Stan van Wingerden (LessWrong, 2023) Importance ●●●○○ Length ●●○○○

The learning coefficient as the scaling exponent of low-loss volume, with pictures; the keystone of NB2. Read it here if you skipped NB2.

One parameter, two exponents. Take d=1 and K_\delta(w)=w^4+\delta w^2 with \delta\ge0.

  • \delta=0: \{K<t\}=\{|w|<t^{1/4}\}, so V(t)\approx2\varphi(0)\,t^{1/4} and \lambda=\tfrac14.
  • \delta>0: for t\ll\delta^2 the quadratic term dominates, \{K<t\}\approx\{|w|<(t/\delta)^{1/2}\}, so V(t)\approx2\varphi(0)(t/\delta)^{1/2} and \lambda=\tfrac12.

So \lambda jumps from \tfrac14 to \tfrac12 as soon as \delta\neq0: in this family the value \tfrac14 occurs at a single point, \delta=0. Exercise 3.1a shows that a finite sample cannot tell small \delta from zero anyway.

The effective exponent. Since \bar F_n\approx\lambda\log n, define the local slope

\lambda_{\rm eff}(n)=\frac{d\bar F_n}{d\log n}=-\frac{d\log\bar Z_n}{d\log n}.

It is a function of n, it tends to \lambda as n\to\infty, and it equals the mean loss n\,\mathbb E_n[K] under \bar p_n\propto\varphi\,e^{-nK} (Exercise 3.1b). It is the slope of a plot of \bar F_n against \log n. For K_\delta with a flat prior it depends on n and \delta only through n\delta^2, and crosses over from \tfrac14 to \tfrac12 around n\sim\delta^{-2} (Exercise 3.1c).

Exercise 3.1a — Where \delta comes from, and when data can see it. (The model is the one in Furman’s notebook.) Let x\sim N(0,1) and use the model p(y\mid x,w)=N(y;\,w^2x,\,\sigma^2) with \sigma^2=\tfrac12. The truth is y=-ax+\varepsilon, \varepsilon\sim N(0,\tfrac12), with a\ge0. For a>0 the truth is outside the model (the model can only make slopes w^2\ge0), and the best fit is w_0=0.

  1. Show that K(w)=w^4+2aw^2, so \delta=2a.
  2. Show that the empirical version K_n(w)=L_n(w)-L_n(0) is K_n(w)=m_2w^4+\delta_nw^2 with m_2=\frac1n\sum_ix_i^2 and \delta_n=-\frac2n\sum_ix_iy_i, and that \delta_n=\delta\,m_2+\xi with \xi approximately N(0,2/n).
  3. For which n can the data distinguish \delta from 0? Compare with the crossover scale n\sim\delta^{-2} above.
  4. What does K_n look like when \delta_n<0? How often does that happen when a=0?
Solution
  1. -\log p(y\mid x,w)=(y-w^2x)^2/(2\sigma^2)+\tfrac12\log(2\pi\sigma^2)=(y-w^2x)^2+c. With y=-ax+\varepsilon, y-w^2x=-(a+w^2)x+\varepsilon, so L(w)=\mathbb E[(a+w^2)^2x^2-2(a+w^2)x\varepsilon+\varepsilon^2]+c=(a+w^2)^2+\tfrac12+c. For a\ge0 this is smallest at w=0, and K(w)=(a+w^2)^2-a^2=w^4+2aw^2.
  2. L_n(w)-L_n(0)=\frac1n\sum_i\big[(y_i-w^2x_i)^2-y_i^2\big]=m_2w^4-2w^2\cdot\frac1n\sum_ix_iy_i, which is m_2w^4+\delta_nw^2. Substituting y_i=-ax_i+\varepsilon_i, \delta_n=2a\,m_2-\frac2n\sum_ix_i\varepsilon_i. The last term has mean 0 and variance \frac4n\,\mathbb E[x^2]\,\mathbb E[\varepsilon^2]=\frac2n, and by the CLT it is close to Gaussian.
  3. The noise in \delta_n is about \sqrt{2/n}, so the data distinguish \delta from 0 only when \delta\gtrsim\sqrt{2/n}, that is n\gtrsim2\delta^{-2}. This is the same scale as the crossover: below it, neither the data nor the free energy can tell \delta from 0.
  4. For \delta_n<0, K_n is a symmetric double well with minima at w=\pm\sqrt{-\delta_n/(2m_2)}, of order n^{-1/4}, and depth \delta_n^2/(4m_2)\sim1/n. When a=0, \delta_n is symmetric about 0, so this happens about half the time. The minima sit at the posterior’s own width n^{-1/4} (Exercise 3.1c), and the depth changes nK_n there by O(1). So at a=0 the empirical loss the posterior sees is a single quartic well or a double well, decided by the sampling noise.

Exercise 3.1b — The effective exponent is a mean loss. Write \mathbb E_n for the average over \bar p_n(w)\propto\varphi(w)e^{-nK(w)}.

  1. Show that \lambda_{\rm eff}(n)=n\,\mathbb E_n[K].
  2. Regular case: K(w)=\tfrac12w^\top Hw on \mathbb R^d with H positive definite and a flat prior. Show \lambda_{\rm eff}(n)=d/2 for every n.
  3. Suppose \bar F_n=\lambda\log n-(m-1)\log\log n+c+o(1), and that this expansion can be differentiated term by term (true when v(t) has a power–log expansion, as in every example here). Show \lambda_{\rm eff}(n)=\lambda-(m-1)/\log n+o(1/\log n). For K=(ab)^2 (\lambda=\tfrac12, m=2), roughly how large must n be for \lambda_{\rm eff} to come within 0.05 of \lambda?
Hint

Differentiate \log\bar Z_n under the integral. For part 2, substitute w=u/\sqrt n.

Solution
  1. \frac{d}{dn}\log\bar Z_n=\frac{\int\varphi\,(-K)\,e^{-nK}}{\int\varphi\,e^{-nK}}=-\mathbb E_n[K], and \frac{d}{d\log n}=n\frac{d}{dn}, so \lambda_{\rm eff}=n\,\mathbb E_n[K]. (In the dictionary of NB1, n plays the role of \beta for the energy K, and this is the identity “mean energy =\partial_\beta F”. It is exact, with no limit taken.)
  2. With w=u/\sqrt n, \bar Z_n=n^{-d/2}\int e^{-\frac12u^\top Hu}du, so \bar F_n=\frac d2\log n+\text{const} and \lambda_{\rm eff}=d/2 exactly. Equivalently, \bar p_n=N(0,(nH)^{-1}) and n\,\mathbb E_n[\tfrac12w^\top Hw]=\tfrac12\operatorname{tr}(I_d)=d/2.
  3. \frac{d}{d\log n}\log\log n=\frac1{\log n}, so \lambda_{\rm eff}=\lambda-\frac{m-1}{\log n}+o(1/\log n). For m=2, 1/\log n<0.05 needs \log n>20, so n\gtrsim e^{20}\approx5\times10^8. Multiplicity is felt for a very long time. (The exact value for K=(ab)^2 with a uniform prior on [-1,1]^2 is \lambda_{\rm eff}=0.45 at n=10^8.)

Exercise 3.1c — Scaling and the crossover. Take K_\delta=w^4+\delta w^2 with a flat prior on all of \mathbb R (a good approximation for a prior that is nearly constant over the region |w|\lesssim n^{-1/4} where the posterior lives).

  1. Substitute w=n^{-1/4}u to show \bar Z_n=n^{-1/4}g(s) with s=\delta\sqrt n and g(s)=\int e^{-u^4-su^2}du. Deduce \lambda_{\rm eff}(n)=\tfrac14+\tfrac s2\langle u^2\rangle_s, where \langle\cdot\rangle_s averages over the density \propto e^{-u^4-su^2}.
  2. Show \lambda_{\rm eff}\to\tfrac14 as s\to0 and \lambda_{\rm eff}\to\tfrac12 as s\to\infty.
  3. Conclude that \lambda_{\rm eff} depends on n and \delta only through n\delta^2=s^2, and give a one-line Fermi argument for the crossover at n\sim\delta^{-2}.
Hint

\frac{d}{ds}\log g=-\langle u^2\rangle_s and \frac{ds}{d\log n}=\frac s2. For large s the su^2 term confines u to |u|\lesssim s^{-1/2}, where u^4 is negligible.

Solution
  1. \int e^{-n(w^4+\delta w^2)}dw=n^{-1/4}\int e^{-u^4-\delta\sqrt n\,u^2}du=n^{-1/4}g(s). So \log\bar Z_n=-\tfrac14\log n+\log g(s) and \lambda_{\rm eff}=\tfrac14-\frac{ds}{d\log n}\frac{g'(s)}{g(s)}=\tfrac14+\tfrac s2\langle u^2\rangle_s.
  2. As s\to0, \langle u^2\rangle_s\to\langle u^2\rangle_0<\infty, so the second term vanishes. As s\to\infty, the density is close to N(0,1/(2s)), so \langle u^2\rangle_s\approx1/(2s) and \lambda_{\rm eff}\to\tfrac14+\tfrac14=\tfrac12.
  3. s^2=n\delta^2, so \lambda_{\rm eff} is a single function of n\delta^2; it equals 0.367 at n\delta^2=1, about halfway. Fermi: \bar p_n sits where nK\sim1. If the quartic term dominates, that is |w|\sim n^{-1/4}, where \delta w^2\sim\delta n^{-1/2} against w^4\sim n^{-1}. Their ratio is \delta\sqrt n=s, so the quadratic term takes over once n\gtrsim\delta^{-2}.

The code computes \lambda_{\rm eff}(n)=n\,\mathbb E_n[K] by quadrature, with a standard normal prior, for several \delta, and replots the curves against n\delta^2. They collapse onto the flat-prior scaling function of Exercise 3.1c except at n\lesssim10, where the prior, not K, sets the slope.

Code (36 lines) 
def lam_eff(K, ns, gamma=1.0, wmax=12.0, N=200_001):
    '''n <K> under the density prop. to exp(-n K(w) - gamma w^2 / 2), for each n in ns (1-D quadrature).

    gamma = 1 is a standard normal prior; gamma = 0 a flat one (then K must confine w within wmax).'''
    s = np.linspace(-1, 1, N)
    w = wmax * np.sinh(8 * s) / np.sinh(8)          # grid dense near w = 0
    logdw, Kw = np.log(np.gradient(w)), K(w)
    out = []
    for n in np.atleast_1d(ns):
        a = -n * Kw - gamma * w**2 / 2 + logdw
        p = np.exp(a - a.max())
        out.append(n * (p * Kw).sum() / p.sum())
    return np.array(out)

3.3 Sampling at temperature

Question. Z_n is a d-dimensional integral we cannot compute. How do we measure \lambda (or \lambda_{\rm eff}) from data, using only samples?

Notation. L_n(w)=-\frac1n\sum_i\log p(X_i\mid w) is the empirical loss, L its population version, w_0 a minimiser of L, and K_n(w)=L_n(w)-L_n(w_0), K(w)=L(w)-L(w_0). The tempered posterior is p_\beta(w\mid D_n)\propto\varphi(w)e^{-n\beta L_n(w)}, with average \mathbb E_\beta; \beta=1 is Bayes. Z_n(\beta)=\int\varphi\,e^{-n\beta L_n} and F_n(\beta)=-\log Z_n(\beta), so F_n=F_n(1) is the free energy. \lambda and m are the learning coefficient (the volume-scaling exponent) and its multiplicity, and \lambda_{\rm eff}(n)=n\,\mathbb E_n[K] is the effective exponent of §3.1.

A widely applicable Bayesian information criterion, Sumio Watanabe (JMLR 14, 2013) Importance ●●●○○ Length ●●●○○

Proves that the posterior mean of nL_n at \beta=1/\log n has the same two leading terms as the free energy, with an O_p(\sqrt{\log n}) error, for singular and misspecified models under his conditions. Read §1 and §4 (Theorems 3–5, Corollaries 1–3); §5 has the proofs.

The estimator

Two exact facts start everything (Exercise 3.1b, part 1, with \beta in place of n):

\frac{dF_n(\beta)}{d\beta}=\mathbb E_\beta[nL_n],\qquad \frac{d}{d\beta}\mathbb E_\beta[nL_n]=-\operatorname{Var}_\beta(nL_n)\le0 .

In the dictionary of NB1 the first is “mean energy =\partial_\beta F”; both hold exactly for any n and d. Since F_n(0)=0 (\varphi is normalised), F_n=\int_0^1\mathbb E_\beta[nL_n]\,d\beta, so some \beta_F\in(0,1) has F_n=\mathbb E_{\beta_F}[nL_n]. It is unique when L_n is not constant, because then \mathbb E_\beta[nL_n] strictly decreases (Watanabe’s Theorem 3). A single posterior average at the right temperature gives the free energy.

Exercise 3.3a — WBIC to leading order. Assume the free-energy formula holds with n\beta in place of n: F_n(\beta)\approx n\beta L_n(w_0)+\lambda\log(n\beta).

  1. Show \mathbb E_\beta[nL_n]\approx nL_n(w_0)+\lambda/\beta.
  2. Show that \mathbb E_\beta[nL_n]\approx F_n at \beta=1/\log n.
  3. Rearrange part 1 into an estimator of \lambda.
  4. Where does this derivation ignore the randomness of the data?
Solution
  1. \frac{d}{d\beta}\big[n\beta L_n(w_0)+\lambda\log n+\lambda\log\beta\big]=nL_n(w_0)+\lambda/\beta.
  2. F_n=F_n(1)\approx nL_n(w_0)+\lambda\log n. Setting nL_n(w_0)+\lambda/\beta equal to it gives \beta=1/\log n. The posterior average of nL_n at that temperature is Watanabe’s WBIC.
  3. \lambda\approx\beta\big(\mathbb E_\beta[nL_n]-nL_n(w_0)\big)=n\beta\big(\mathbb E_\beta[L_n]-L_n(w_0)\big).
  4. In the assumption. The formula \lambda\log(n\beta) is the one for \bar Z, built from the population K. With K_n in its place, nK_n(w)-nK(w) is a sum of n centred terms \log\frac{p(X_i\mid w_0)}{p(X_i\mid w)}-K(w). In the realisable case each has variance of order K(w) near w_0, so the sum is of order \sqrt{nK}. Where the tempered posterior sits, nK\sim\lambda/\beta, so this is of order \sqrt{\lambda/\beta}: after multiplying by \beta, an error of order \sqrt{\lambda\beta} in the estimator. That is the U_n term below. Part 2 also drops the -(m-1)\log\log n term.

What Watanabe proves. For \beta=\beta_0/\log n with \beta_0>0 a constant, under his conditions (which cover realisable models, singular or not, and regular ones), Theorem 4 of the WBIC paper gives

\mathbb E_\beta[nL_n]=nL_n(w_0)+\frac{\lambda}{\beta}+U_n\sqrt{\frac{\lambda}{2\beta}}+O_p(1),

where U_n has mean zero and tends in law to a Gaussian, with \mathbb E[U_n^2]<1 when the model is realisable. At \beta_0=1 this is \mathrm{WBIC}=nL_n(w_0)+\lambda\log n+O_p(\sqrt{\log n}), which has the same two leading terms as F_n. Multiplying by \beta, the estimator of part 3 is

\hat\lambda=n\beta\big(\mathbb E_\beta[L_n]-L_n(w_0)\big)=\lambda+U_n\sqrt{\lambda\beta/2}+O_p(\beta).

The local estimator. Lau et al. make two changes. They replace the prior by a Gaussian of precision \gamma centred on a parameter w^* of interest (usually a trained network), and set \beta=\beta^*=1/\log n:

p(w;w^*,\beta,\gamma)\propto\exp\Big(-n\beta L_n(w)-\frac\gamma2\|w-w^*\|^2\Big),\qquad \hat\lambda(w^*)=n\beta^*\big(\mathbb E_{w^*,\beta^*,\gamma}[L_n]-L_n(w^*)\big).

This is the local learning coefficient (LLC) estimator. Lau et al. show that the corresponding average estimates a localised free energy (their Appendix D), and conjecture that the limit is the local learning coefficient \lambda(w^*) under conditions on \gamma.

Exercise 3.3b — What \hat\lambda measures, in two idealisations. Use the global estimator (\gamma=0, flat prior, w^*=w_0). J=\nabla^2L(w_0) is the Hessian (called H in NB1) and C the covariance of \nabla\log p(X\mid w_0).

  1. No data noise. Replace L_n by L, so K_n becomes K. Show \hat\lambda=\lambda_{\rm eff}(n\beta), the effective exponent of §3.1 at sample size n\beta.
  2. Regular, with data noise. Take K_n(w)=\tfrac12(w-\hat w)^\top J(w-\hat w)-\tfrac12\hat w^\top J\hat w on \mathbb R^d (the quadratic expansion around w_0=0, with \hat w the minimiser of L_n). Show \hat\lambda=\frac d2-\frac{n\beta}2\hat w^\top J\hat w. In a well-specified model n\hat w^\top J\hat w is approximately \chi^2_d (NB1 §2). Deduce \mathbb E[\hat\lambda]\approx\frac d2(1-\beta). What changes under misspecification?
Solution
  1. With K in place of K_n the tempered posterior is \propto\varphi\,e^{-n\beta K}, which is \bar p_{n'} with n'=n\beta. So \hat\lambda=n'\,\mathbb E_{n'}[K]=\lambda_{\rm eff}(n') by Exercise 3.1b. Changing \beta is the same as changing n to n\beta.
  2. The tempered posterior is N\big(\hat w,(n\beta J)^{-1}\big), so \mathbb E_\beta[K_n]=\tfrac12\operatorname{tr}\big(J(n\beta J)^{-1}\big)-\tfrac12\hat w^\top J\hat w=\frac d{2n\beta}-\tfrac12\hat w^\top J\hat w and \hat\lambda=n\beta\,\mathbb E_\beta[K_n]=\frac d2-\frac{n\beta}2\hat w^\top J\hat w. With n\hat w^\top J\hat w\approx\chi^2_d (mean d), \mathbb E[\hat\lambda]\approx\frac d2(1-\beta). The reference point L_n(w_0) lies above the minimum of L_n by \frac12\hat w^\top J\hat w, and n\beta times that is an O(\beta) bias. Under misspecification \hat w\approx N(0,J^{-1}CJ^{-1}/n) (NB1 §2), so \mathbb E[n\hat w^\top J\hat w]=\operatorname{tr}(J^{-1}C) and \mathbb E[\hat\lambda]\approx\frac d2-\frac\beta2\operatorname{tr}(J^{-1}C).

So \hat\lambda differs from \lambda for three separate reasons, and the code below measures each: the finite scale, \lambda_{\rm eff}(n\beta)-\lambda (part 1); the data, an O_p(\sqrt\beta) random term (root mean square below \sqrt{\lambda\beta/2} in realisable models) and an O(\beta) bias (part 2 and Watanabe’s theorem); and the sampler.

Exercise 3.3c — What \gamma does. In one dimension, take K(w)=\tfrac12hw^2 (no data noise) and the localised posterior \propto e^{-n\beta K(w)-\gamma w^2/2} centred at w^*=w_0=0. Show \hat\lambda=\tfrac12\big/\big(1+\gamma/(n\beta h)\big). Which directions does the localisation remove from the count?

Solution

The localised posterior is N\big(0,1/(n\beta h+\gamma)\big), so \hat\lambda=n\beta\cdot\tfrac12h\cdot\frac1{n\beta h+\gamma}=\frac12\cdot\frac1{1+\gamma/(n\beta h)}. A direction with curvature h\gg\gamma/(n\beta) counts fully (\tfrac12). A direction with h\ll\gamma/(n\beta) is confined by the Gaussian before the loss can confine it, and its contribution is negligible; in between it is partly counted. In distance terms, the localisation ignores how the loss behaves farther than about \gamma^{-1/2} from w^*.

The sampler, and three checks

SGLD. We need samples from \propto e^{-U(w)} with U(w)=n\beta L_n(w)+\frac\gamma2\|w-w^*\|^2. The Langevin diffusion dw=-\tfrac12\nabla U\,dt+dB_t has exactly this stationary density. Its Euler step with step size \epsilon is \Delta w=-\frac\epsilon2\nabla U(w)+\sqrt\epsilon\,\xi, \xi\sim N(0,I_d). Stochastic gradient Langevin dynamics (SGLD) replaces \nabla L_n by its average over a random minibatch of m samples. This is Lau et al.’s update (their §4.4):

\Delta w_t=-\frac\epsilon2\Big(n\beta\,\widehat{\nabla L_n}(w_t)+\gamma(w_t-w^*)\Big)+\sqrt\epsilon\,\xi_t, \qquad \widehat{\nabla L_n}=\frac1m\sum_{i\in B_t}\nabla\big(-\log p(X_i\mid w_t)\big).

The tempering lives in U, through n\beta; the Langevin noise itself is at unit temperature. SGLD samples e^{-U} only as \epsilon\to0. For a well-behaved U a finite step biases the samples by O(\epsilon); for a steep one such as w^4 a step too large for the region the chain reaches can make it diverge. The minibatch adds gradient noise, and a finite chain may not have mixed. These are sampler errors, not properties of the target. Lau et al. (Appendix H) tune \epsilon until a Metropolis acceptance check passes 90–95% of proposals and the loss trace is flat; here we keep \epsilon a small fraction of the inverse curvature.

def sgld_llc(grad, loss, w_star, nbeta, gamma, eps, steps, rng, burn=0.25):
    '''SGLD chains for the localised tempered posterior, prop. to exp(-nbeta L_n(w) - gamma/2 |w - w_star|^2).

    w_star : array (chains, d), every row the centre w* (each chain starts there)
    grad   : grad(w, rng) -> (chains, d), a minibatch estimate of grad L_n at each chain's w
    loss   : loss(w) -> (chains,), L_n(w) - L_n(w*) at each chain's w
    Returns lambda-hat for each chain: nbeta times the average of loss over the draws after burn-in.
    '''
    w = w_star.copy()
    total, count = 0.0, 0
    for t in range(steps):
        drift = nbeta * grad(w, rng) + gamma * (w - w_star)
        w = w - 0.5 * eps * drift + np.sqrt(eps) * rng.standard_normal(w.shape)
        if t >= burn * steps:
            total, count = total + loss(w), count + 1
    return nbeta * total / count

Solution

By Exercise 3.3b, part 1, \hat\lambda(\beta)\approx\lambda_{\rm eff}(n\beta): the crossover curve of §3.1 with n\beta on the horizontal axis. It is near \tfrac14 for n\beta\ll\delta^{-2}=10^4, near \tfrac12 for n\beta\gg10^4, and crosses over across a few decades around n\beta\sim10^4. \beta^*=1/\log10^6=0.072, so n\beta^*\approx7\times10^4 and n\beta^*\delta^2\approx7, past the middle of the crossover: \hat\lambda(\beta^*)\approx0.45, neither \tfrac14 nor \lambda=\tfrac12.

The data noise is small: \sqrt{2/n}=0.0014 against \delta=0.01. The bias of Exercise 3.3b comes from the linear term of K_n at w_0, and here K_n=m_2w^4+\delta_nw^2 has none: the model is even in w, so the minimiser of L_n is w_0=0 itself whenever \delta_n>0. So the points should follow the curve at every \beta, up to sampler error and small shifts from m_2\ne1 and \delta_n\ne\delta (a few thousandths here).

# Normal crossings: model y = w1^k1 w2^k2 x, truth y = noise (variance 1/2), so K(w) = (w1^k1 w2^k2)^2.
def lam_eff_2d(k1, k2, nb, gamma, N=2001, wmax=8.0):
    '''nb <K> under exp(-nb K - gamma |w|^2 / 2), by quadrature on a 2-D grid.'''
    s = np.linspace(-1, 1, N)
    w = wmax * np.sinh(6 * s) / np.sinh(6)
    a, b = np.meshgrid(w, w, indexing="ij")
    K = (a**k1 * b**k2)**2
    lw = np.log(np.gradient(w))
    logp = -nb * K - gamma * (a**2 + b**2) / 2 + lw[:, None] + lw[None, :]
    p = np.exp(logp - logp.max())
    return nb * (p * K).sum() / p.sum()


def normal_crossings(cases, m2, mxy, chains, nb, gamma, eps, steps, rng):
    '''lambda-hat for each case, each data set (m2 = mean x^2, mxy = mean xy) and each chain.'''
    k = np.array(cases, float)
    k1, k2 = [np.repeat(k[:, j], len(m2) * chains)[:, None] for j in (0, 1)]
    m2 = np.tile(np.repeat(m2, chains), len(cases))[:, None]
    mxy = np.tile(np.repeat(mxy, chains), len(cases))[:, None]

    def f_and_grad(w):                                   # f = w1^k1 w2^k2 and its gradient
        a, b = w[:, :1], w[:, 1:]
        fa = np.where(k1 > 0, k1 * a**np.maximum(k1 - 1, 0) * b**k2, 0.0)
        fb = np.where(k2 > 0, k2 * b**np.maximum(k2 - 1, 0) * a**k1, 0.0)
        return a**k1 * b**k2, np.hstack([fa, fb])

    def loss(w):                                         # L_n(w) - L_n(0) = m2 f^2 - 2 mxy f
        f, _ = f_and_grad(w)
        return (m2 * f**2 - 2 * mxy * f)[:, 0]

    def grad(w, rng):                                    # full batch, via m2 and mxy
        f, df = f_and_grad(w)
        return (2 * m2 * f - 2 * mxy) * df

    lh = sgld_llc(grad, loss, np.zeros((len(k1), 2)), nb, gamma, eps, steps, rng)
    return lh.reshape(len(cases), -1, chains)

A linear network with known \lambda. The last check is a two-layer linear network f(x)=BAx with A\in\mathbb R^{H\times M} and B\in\mathbb R^{N\times H} (reduced-rank regression), so d=H(M+N). The truth is y=B_0A_0x+\varepsilon, \varepsilon\sim N(0,I_N), with \operatorname{rank}(B_0A_0)=r. (H is a width here, not a Hessian.) def aoyagi_watanabe(M, N, H, r):
    '''Learning coefficient and multiplicity of the two-layer linear network / reduced-rank regression.'''
    if N + r <= M + H and M + r <= N + H and H + r <= M + N:
        s = 2 * (H + r) * (M + N) - (M - N)**2 - (H + r)**2
        return (s / 8, 1) if (M + H + N + r) % 2 == 0 else ((s + 1) / 8, 2)
    if M + H < N + r:
        return (H * M - H * r + N * r) / 2, 1
    if N + H < M + r:
        return (H * N - H * r + M * r) / 2, 1
    return M * N / 2, 1

        res = h @ B.transpose(0, 2, 1) - yb
        gA = (res @ B).transpose(0, 2, 1) @ xb / b
        gB = res.transpose(0, 2, 1) @ h / b
        return np.hstack([gA.reshape(len(w), -1), gB.reshape(len(w), -1)])

    def Ln(w):                         # full-batch L_n, up to a constant, from the second moments
        A, B = unpack(w)
        P = B @ A
        return 0.5 * np.einsum("cij,jk,cik->c", P, Sxx, P) - np.einsum("cij,ji->c", P, Sxy)

What the hyperparameters do. Each knob of the estimator is either a scale or a sampler setting:

  • \beta. Without data noise and with \gamma=0, \hat\lambda(\beta)=\lambda_{\rm eff}(n\beta) exactly (Exercise 3.3b), and the \beta-sweep above is the crossover curve of §3.1 drawn against n\beta. In that idealisation the \beta-dependence of \hat\lambda is exactly the n-dependence of \lambda_{\rm eff}.
  • \gamma. A distance scale, about \gamma^{-1/2} around w^*: directions with curvature well below \gamma/(n\beta) are suppressed, and those near it are partly counted (Exercise 3.3c).
  • \epsilon, chain length, minibatch size. Sampler accuracy only. They have no counterpart in the target distribution, so tune them until \hat\lambda stops depending on them.
