# Mysteries of Deep Learning: notebooks

Six workbooks. Pick whatever interests you; the sections are largely independent, and nobody is expected to finish everything.

Each workbook is a single HTML page: open it in any browser (math is typeset by KaTeX, loaded from a CDN, so the first load needs a network connection). Every exercise is followed by its worked **solution**, folded away until you click "Solution"; hints are folded the same way. The "Show all solutions" button expands or collapses every solution at once, and printing the page prints them all. Solutions are for everyone; use them however helps you learn.

Each workbook opens with a route that links to its sections. Every reading carries ARENA-style scores, **Importance** and **Length** (1–5 dots each; the key is under the contents). Books are not scored: they are listed as reference links at the bottom of a reading list. Sections and subsections are folded; open what you want, or use "Expand all sections". The interactive figures are self-contained HTML files in [`assets/interactive/`](assets/interactive/README.md).

## For maintainers

- Never hand-edit the `.html` files. Each is generated from one builder: `build_wbN.py`. WB2's cells live in per-section modules listed in `build_wb2.py` (`wb2_s1.py`, `wb2_s1e.py`, `wb2_s1f.py`, `wb2_s2.py`, `wb2_s3.py`, `wb2_s4.py`, which import the newer `wb2_new_*.py` pieces); pre-restructure sources are in `_old_wb2/`.
- Build with `python build_wbN.py` (needs `pandoc` on PATH; it converts each cell's Markdown, including `$…$`/`$$…$$` math, to HTML at build time). Use `--check` to validate a builder and report whether its notebook is stale; it changes nothing on disk.
- Shared helpers are in `nbkit.py`: `reading(..., importance=, length=)` requires both scores (1–5); books go in `references(book(...), ...)` at the end of a list; `markdown()` cells become the page; every `##`/`###`/`####` section is folded into a collapsed `<details class="sec">` at render time; each `answer()` cell becomes a collapsed "Solution" block after the cell before it, and `<details><summary>Hint</summary>` blocks in Markdown become folded hints. The page template (CSS, contents sidebar, KaTeX loader) is at the bottom of `nbkit.py`. The build fails on unbalanced `<details>`, TeX left outside math, missing local link targets, and dangling `#anchors`.
- The older exercises/solutions `.ipynb` pairs are kept, unmaintained, in `_old_ipynb/`.
- Numerical checks for WB2 are in `checks/` (`wb2a_check.py`, `wb2b_check.py` for the older material; `wb2_new_*_check.py` for the 2026-10-09 additions).
- Current editorial guidance is in [`../reviews/2026-10-08-editorial-brief.md`](../reviews/2026-10-08-editorial-brief.md). The per-workbook review records are in the same directory. Older workbook specs are historical and do not override the brief.
