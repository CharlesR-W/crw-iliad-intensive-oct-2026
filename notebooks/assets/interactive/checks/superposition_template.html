Superposition in a toy autoencoder

The toy model of Elhage et al., "Toy Models of Superposition" (2022), in their notation: features x ∈ ℝn, each xi = 0 with probability S (the sparsity) and otherwise ~ Uniform[0,1]; reconstruction x′ = ReLU(W⊤W x + b) with W ∈ ℝm×n; loss L = 𝔼 Σi Ii(xi − x′i)². Column Wi ∈ ℝm is where feature i is stored.
