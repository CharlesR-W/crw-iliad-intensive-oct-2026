## Corrections to preserve through the rewrite

1. **WB5, PRH global-minimum equation: noncommuting inverses are reversed.** The displayed equation beginning `W_D\\cdots W_1=(M^O)^{-1}V^*` currently ends in `(M^I)^{-1}Z_A^{-1}`. From the notebook's own definition, the end-to-end map is $M^O W_D\cdots W_1 M^I Z_A$. Hence the correct right side is $(M^O)^{-1}V^*Z_A^{-1}(M^I)^{-1}$. This error is also in equation (10) of the linked paper; source fidelity does not repair the algebra. Add $\Sigma_x\succ0$ if claiming equality of maps everywhere, or restrict it to input support.

2. **WB5, PRH Step 3: keep the loss normalization consistent.** For the stated $\ell=\|f-y\|^2$, the actual backpropagated gradient at a fitted target is $g=-2\bar M^T\epsilon$. Thus the left side of the factorized balance equation has a factor of 4: $4\mathbb E\|h\|^2 W_{i+1}^T\bar M^T\Sigma_\epsilon\bar M W_{i+1}=\mathbb E\|g\|^2W_iN\Sigma_xN^TW_i^T$. Consequently the later $c$ is $\mathbb E\|g\|^2/(4\mathbb E\|h\|^2)$. Simplest correction: use $\ell=\tfrac12\|f-y\|^2$ throughout this derivation, change its minimum to $\tfrac12\operatorname{Tr}\Sigma_\epsilon$, and keep the existing $c$. The common factor does not change the qualitative alignment result, but the worked answer must be internally consistent.

3. **WB5, PRH inverse, uniqueness, and representation qualifications.** The use of $\Sigma_x^{-1/2}$ requires positive-definite input second moment; otherwise use its pseudoinverse and restrict to the data support. Convexity along a one-parameter scaling direction does not prove a unique minimum on the whole symmetry orbit: orthogonal changes preserve $S$, and null directions can make the one-dimensional function constant. Replace “each symmetry orbit has a unique entropy-minimizing point” with the stationarity/balance implication actually used. “Exactly linear CKA=1” additionally requires centered Gram matrices (standard CKA centers); proportional uncentered Grams imply CKA=1 but the converse allows translations. The map between unequal-width representations is an isometry on their occupied subspaces, not necessarily a matrix with orthonormal columns on the larger full ambient space.

4. **WB5, PRH theorem versus optimizer convergence.** The reading blurb says SGD networks “end up” aligned, while the careful caveat later says convergence is not proved. Put the caveat in the first substantive summary: characterize minima selected by the small-positive-step modified-objective approximation. The paper explicitly leaves a convergence proof to future work in its Remark. Keep this limitation near the claim, not only after the exercise. [Ziyin & Chuang, equations (12)–(13), Theorem 1, and Remark](https://arxiv.org/html/2507.01098v1).

5. **WB4, Solomonoff conditional telescoping omits the root mass.** With the displayed semimeasure and ratio conditionals, $\prod_{t=1}^n\xi(x_t\mid x_{<t})=\xi(x_{1:n})/\xi(\epsilon)$, not $\xi(x_{1:n})$. The exact regret identity is $\ln[\mu(x_{1:n})\xi(\epsilon)/\xi(x_{1:n})]$ for a normalized environment. Since $\xi(\epsilon)\le1$, the stated upper bound $K(\mu)\ln2$ survives. The ratios are subprobabilities, so “KL divergence between next-symbol predictors” should either include a termination outcome (true environment gives it probability zero) or explicitly normalize predictions. Define $K(\nu)$ for a lower-semicomputable semimeasure as the prefix description length of an approximation procedure, not as a program computing all its values. [Rathmanner & Hutter](https://arxiv.org/html/1105.5721).

6. **WB3, support preservation does not prove that RL cannot learn new computations.** The KL optimum is correct for $\beta>0$, finite normalizer, and policies absolutely continuous with respect to $\pi_0$. Full-support softmax models already give positive mass to every finite output; preserving support therefore says almost nothing about what capabilities/algorithms parameter updates can acquire. Remove the deduction “rather than building something new” from the mathematical result. The persona decomposition is an optional modeling assumption, not established by the variational identity. Also unchanged persona weights require equal exponential reward moments, not merely equal mean reward: at $\beta=1$, deterministic reward 1 and equally likely rewards 0/2 have the same mean but moments $e$ and $(1+e^2)/2$. Identical output distributions do suffice. [DPO paper, equation (4) and Appendix A.1](https://arxiv.org/html/2305.18290v3).

7. **WB3, bit counts are code lengths, not measured learning signal.** “Every one of those bits was a training signal” is unjustified: residual cross-entropy includes irreducible conditional entropy, and label determinism given an image does not imply an unknown label mapping is uninformative to a learner. Keep the numeric entropy/code-size exercise, drop the conclusion that it measures transferable information or parameter learning. Arithmetic coding constructs a code of length at most $-\log_2q(x)+2$; it is not the “shortest code for that sequence,” which could be much shorter. State fixed sequence length or an EOS convention when claiming final intervals for different sequences are disjoint.

8. **WB5, spectral boundary and finite-sample scope.** The independent tail/bias balance verifies the quoted strict-regime exponents, but at $\alpha'-1=2\alpha$ the harmonic sum adds a logarithm: noiseless risk is of order $n^{-2\alpha}\log n$. If giving the noisy boundary too, minimizing $K^{-s}\log K+\sigma^2K/n$ with $s=2\alpha$ yields an extra $(\log n)^{1/(s+1)}$. State “away from the boundary, up to logarithmic factors” if not teaching this edge case. Deterministic equivalents are asymptotic approximations, not the exact finite-$n$ risk; the existing figure’s “exact curve” wording is too strong. [Li et al., asymptotic learning curves and saturation](https://arxiv.org/html/2309.13337).

## Added audit: WB1 planning as inference

Reviewed the fixed baseline `build_wb1.py`, section 3, and [Levine, sections 2–3](https://arxiv.org/html/1805.00909). The source explicitly distinguishes exact inference in deterministic dynamics from structured variational inference in stochastic dynamics. Its finite-horizon setup does not establish that ordinary statistical learning and reward optimization have identical objectives.

- **Correct the zero-temperature claim after the exact-inference backup.** The text says the displayed $Q=r+\log\mathbb E\exp V$ becomes the usual Bellman equation as temperature vanishes. With stochastic dynamics, $\alpha\log\mathbb E\exp(V/\alpha)$ tends to the essential supremum of $V$ over reachable next states, not $\mathbb EV$. This is the risk-seeking pathology described in the next subsection; it persists in the zero-temperature limit. Restrict the ordinary-Bellman claim to deterministic dynamics, or apply it only after fixing the dynamics in the variational family. The finite-horizon time indices should remain on $Q_t,V_t,\pi_t$.
- **Normalize the action prior consistently.** The line calling $p(\tau)=p(s_1)\prod P$ a probability has omitted the action-prior factors. If there are $m$ actions and a uniform prior at each of $T$ steps, the normalized trajectory probability contains $m^{-T}$. Therefore the KL identity is $D_{KL}(q\|p(\tau\mid\mathcal O))=-\mathbb E_q\sum_t(r_t+H(\pi_t))+T\ln m+\ln p(\mathcal O)$. The entropy objective is an ELBO only after subtracting $T\ln m$. Dropping this constant is harmless for the optimizer, but not for an equality to a probability or an evidence lower bound. A clean alternative is to retain $\pi_0(a\mid s)$ everywhere: the objective is $\mathbb E_q\sum_t[r_t-D_{KL}(\pi_t\|\pi_0)]$, $V_t=\log\sum_a\pi_0(a\mid s)e^{Q_t(s,a)}$, and $\pi_t^*=\pi_0e^{Q_t-V_t}$. Uniform priors on unbounded continuous action spaces do not exist; specify a finite action set or a normalized reference density.
- **State the planning hypotheses.** Deterministic dynamics make feasible trajectories equally likely only after fixing the initial state and using a common finite action set with uniform action priors (and fixed horizon). Nonuniform initial probabilities remain even with deterministic transitions. Shifting rewards changes posterior distributions only by a common factor for fixed horizon; retain that assumption. Distinguish finite-horizon undiscounted formulas from section 1’s infinite-horizon discounted Bellman equation.
- **Limit the one-step formula to its one-step problem.** $\pi^*(a)\propto\pi_0(a)e^{r(a)}$ is valid for a bandit/fixed-prompt distributional choice. Sequential control uses $Q_t(s,a)$, which includes downstream value; it cannot generally be replaced by immediate reward.
- **Verified:** the fixed-dynamics variational cancellation and expected-reward-plus-entropy optimizer are correct once action-prior constants are handled. Jensen’s risk-seeking explanation is correct. The gamble calculation $\log[pe^R+(1-p)e^{-\infty}]=R+\log p$, versus expected return $-\infty$, is correct; a finite large negative payoff can replace $-\infty$ if all expectations should stay finite.

## Additional WB4 scope correction if this survives editing

The closing sentence that every PAC-Bayes story reaches a trained network “only if SGD approximately samples the posterior” is false in general. PAC-Bayes bounds can hold simultaneously for arbitrary data-dependent distributions; choosing a distribution around SGD weights does not require those weights to be Bayesian samples. A further argument is needed to transfer a randomized predictor’s guarantee to a single deterministic network, but posterior sampling is not the only route. [Perez-Ortiz et al., Tighter Risk Certificates for Neural Networks](https://jmlr.org/papers/v22/20-879.html) illustrates direct learning and certification of such distributions.
